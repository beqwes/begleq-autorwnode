# begleq-autorwnode

Настройка ноды Remnawave одним скриптом. Запускается на самом сервере,
ставить ничего у себя не нужно.

Что делает: готовит систему (пакеты, swap, BBR, лимиты, docker, ufw, fail2ban),
выпускает сертификат Let's Encrypt, поднимает ноду и nginx с сайтом-заглушкой,
проверяет результат и вешает отчёт о состоянии ноды при входе по SSH.

## Установка

На сервере, от root:

```bash
curl -fsSL https://raw.githubusercontent.com/beqwes/begleq-autorwnode/main/node-setup.sh -o node-setup.sh && bash node-setup.sh
```

Скрипт спросит SECRET_KEY, домен, порт и остальное. Повторный запуск ничего
не ломает: существующий ключ и чужой `docker-compose.yml` не трогаются.

## Полезные режимы

Только посмотреть состояние ноды, ничего не меняя:

```bash
bash node-setup.sh --status-only
```

Поставить отчёт при входе на уже настроенную ноду:

```bash
bash node-setup.sh --motd-only
```

Без вопросов:

```bash
bash node-setup.sh --secret 'КЛЮЧ' --domain example.com --panel-ip 203.0.113.10 --yes
```

Полный список флагов — `bash node-setup.sh --help`.

## Про сайт-заглушку

Если указать домен, скрипт выпускает сертификат и поднимает рядом с нодой
nginx с сайтом-заглушкой. Сайт генерируется случайным: один из шести
музыкальных стилей (breakcore, lo-fi, dnb, synthwave, phonk, ambient), своё
название, палитра, шрифты и трек-лист — две ноды не выглядят одинаково.
Конкретный стиль задаётся флагом `--site-theme`.

Заглушку отдаёт не nginx напрямую, а Xray по правилам инбаунда из панели:
в `serverNames` должен быть домен ноды, а `dest` вести на `/dev/shm/nginx.sock`
или `127.0.0.1:9443` — скрипт слушает оба варианта и сам сверяет настройки
с панелью.

## Требования

Debian или Ubuntu, root. Остальное скрипт доставит сам.
